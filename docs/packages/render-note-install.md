# Render Note installation

The first runtime integration deliberately requires no production Trilium source change. It uses an existing JSX Render Note and frontend Script API for reads/creation, plus Trilium's existing authenticated note-attribute endpoints for updating labels and relations.

1. Enable the JSX language in **Options → Code Notes**.
2. Copy [`scripts/community-packages.tsx`](../scripts/community-packages.tsx) into the Trilium script-deployer `scripts/` directory, or create a Render Note with a child JSX Code Note containing the file contents.
3. Deploy the script with the existing script-deployer. It creates **Community Packages** under the Scripts note.
4. Open the Render Note, enter a registry URL, and save it.

The included [`registry.json`](../registry.json) is a static catalog index for the current Wordcount, LanguageTool, Web Server, Gmail Ingest, and Ikmal Tools packages. It can be served from GitHub Pages, a raw GitHub URL, object storage, or another HTTPS static host. The package repositories and their declared artifact paths must be publicly reachable before users can install from the catalog. Until a hosted catalog is established, use the experimental [integrated Trilium branch](https://github.com/iansherr/Trilium/tree/integration/plugins) with `pnpm serve:registry` from this local repository for end-to-end testing.

The registry is a JSON document matching [`schema/trilium-package.schema.json`](../schema/trilium-package.schema.json), for example. It may contain ordinary package manifests and `kind: "bundle"` entries. Bundle `components` must point to package IDs published in the same registry; the bundle itself never owns artifact notes.

Package manifests may also publish `deprecated` and an optional `deprecationMessage`, `maintenance` (`active`, `slow`, or `unmaintained`), `securityStatus` (`unreviewed`, `reviewed`, or `warning`), `lastValidatedAt`, maintainer metadata, and an artifact `integrity` value using the `sha256-...` SRI format. Artifact integrity is required for registry packages and is verified against the downloaded bytes before creating any artifact notes. Registries and artifacts must use HTTPS, except for localhost development sources. Deprecated packages are hidden from new installs and update prompts by default; the manager and native Plugins settings tab provide an opt-in to include them. Existing installations remain visible and show the registry status.

```json
{
  "schemaVersion": 1,
  "generatedAt": "2026-07-30T00:00:00Z",
  "packages": []
}
```

The catalog displays bundle components with independent checkboxes. Installing a selection resolves dependencies and stages the selected package manifests in one transaction; the resulting packages remain separately manageable in **Settings → Plugins**. A bundle does not create a shared package owner for those components.

Installation creates a managed package subtree under Trilium's hidden system area. Package artifacts are tagged with `packageManaged`, `packageOwner`, `packageVersion`, and `packageArtifact`. Activation labels are created in their `disabled:*` form, so installing a package does not execute it. Launchers remain under **Available Launchers** until the package is enabled, and are moved to **Visible Launchers** only while enabled. The manager only enables the other activation labels when the user presses **Enable**. Package-defined settings appear under **Configure** and are stored as labels on the package manifest note.

Explicit ownership-transfer migrations require a staged source replacement and destination package, verify both declared SRI values, preserve user branches, and retain rollback markers until the whole transaction completes. The staged Ikmal split remains unpublished until its cloned-vault rehearsal passes.

The **Archive** action is a recoverable uninstall: it disables the package and archives its managed notes without deleting them. Lifecycle mutations acquire Trilium's authenticated, CSRF-protected `community-packages` operation lease so two tabs cannot mutate package state concurrently. The five-minute lease is renewed during long operations and is only a concurrency guard; transaction markers remain necessary for restart recovery. The lease is held by the Trilium server process and coordinates clients connected to that instance; it is not a distributed lock across multiple server processes. The **Updates** section stages the replacement under a transaction marker, then archives the old managed subtree only after the replacement has been downloaded and created. If staging or replacement fails, the transaction notes are archived and the previous package is restored to its prior enabled state. Installed packages are checked against the manifest for a present manifest note and all declared artifacts; broken packages expose a recoverable **Repair** action that reinstalls the catalog version while preserving package settings, pin state, and (when repairing) enabled state. Install, update, and repair actions resolve required dependencies in one transaction and install missing catalog entries disabled before continuing. Required dependencies must also be enabled before a dependent package can be enabled; a required dependency cannot be disabled while an enabled dependent uses it, and cannot be uninstalled while any installed dependent remains. Manifest-declared Trilium compatibility is enforced against the running version. Each lifecycle action asks for explicit confirmation with the package permissions and dependency list. An optional source-host allowlist can restrict artifact downloads to approved exact or wildcard hosts. Optional dependencies remain non-blocking; unavailable, incompatible, cyclic, out-of-range, or network-disallowed dependencies stop the operation before any download begins. Installed packages can be pinned with the `packagePinned` label to suppress update prompts until explicitly unpinned. Update checks are opt-in and low-frequency while the manager or native Plugins page is open; they reuse the same registry and pinned-package rules. The package manager itself is already a normal Trilium note and can be pinned or linked wherever convenient.
